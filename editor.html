Рецепт начинается здесь.

Напишите сами или загрузите JSON от ИИ. Отредактируйте поля, посмотрите результат и скачайте файлы для публикации. Редактор не имеет доступа к GitHub и не публикует ничего автоматически.

Черновик сохраняется в этом браузере.

О блюде

Новое фото будет уменьшено до 1440 px и подготовлено в JPEG. Перед публикацией скачайте его отдельно.

Варианты блюда

Ингредиенты

Количество — с единицей измерения: «200 г», «2 шт (~120 г)». КБЖУ на 100 г берите с этикетки. Автоподсказки являются оценкой — проверьте их.

Готовый вес нужен для расчёта на 100 г. После изменения ингредиентов пересчитайте КБЖУ перед экспортом. Для незнакомого продукта укажите этикетку.

Шаги

Используйте кнопку «Вставить продукт» внутри шага: такая ссылка обновит и название, и количество при заменах. Время и температуру пишите обычным текстом.

Проверить и опубликовать

Скачайте JSON и новое фото, если оно загружено. Добавление в репозиторий выполняется командой node scripts/add-recipe.mjs recipe.json. Подробности — в файле UPDATE-GUIDE.md из архива.

Черновик хранится только на этом устройстве. Скачивайте JSON для резервной копии.
