---
description: Быстрое добавление нового ПП-рецепта на сайт за 10 секунд через scripts/add-recipe.mjs
---
Добавь на сайт новый ПП-рецепт по данным ниже:

$ARGUMENTS

Строго соблюдай алгоритм:
1. НЕ читай `assets/app.js`, `assets/styles.css` и `assets/recipes-data.js`.
2. Рассчитай точное КБЖУ (`total` на весь объём и `per100` на 100 г готового блюда с учётом ужарки/уварки). В каждом массиве `macros` обязательно укажи `Белки`, `Жиры`, `Углеводы`, `Клетчатка`.
3. Добавь в корень JSON-объекта рецепта поле `"imagePrompt"` с подробным англоязычным промптом фуд-фотографии готового блюда в стиле Kinfolk (светлая керамика, бежевый лён, дневной свет, без текста).
4. Запиши JSON рецепта в файл `new-recipe.json` и выполни в PowerShell (через `;`, без `&&`):
   `node scripts/add-recipe.mjs new-recipe.json --cleanup`
5. Если пользователь попросил выложить на сайт, выполни:
   `git add .; git commit -m "feat: add new recipe"; git push`
