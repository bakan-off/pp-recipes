# Добавление нового рецепта (/add-recipe)

Когда пользователь просит добавить рецепт (например: «добавь рецепт...» и скидывает сырой текст из видео, заметку или фото пачек продуктов), выполняй строго этот быстрый алгоритм:

1. **ЗАПРЕЩЕНО тратить время на чтение ядра**:
   НЕ читай и НЕ редактируй `assets/app.js`, `assets/styles.css` и НЕ читай целиком `assets/recipes-data.js`. Вся вставка и сборка автоматизированы через `scripts/add-recipe.mjs`.

2. **Расчёт КБЖУ и структуры рецепта**:
   - Придумай латинский `slug` (например, ` cottage-cheese-waffles.html`) и имя картинки `image` (`cottage-cheese-waffles.jpg`).
   - Выбери категорию строго из списка: `Завтраки`, `Основные блюда`, `Десерты`, `Выпечка`, `Напитки`.
   - Посчитай точное КБЖУ всех ингредиентов:
     - `total`: сумма калорий, белков, жиров, углеводов и клетчатки на весь объём рецепта.
     - `per100`: КБЖУ на **100 г готового блюда** с учётом ужарки/уварки (мясо/птица в духовке или аэрогриле теряет ~15-20% влаги; выпечка из творога теряет ~10%; сухие макароны/крупы при варке увеличиваются в весе в ~2.4 раза).
   - Если блюдо составное (например, основное + гарнир + соус), создай несколько вкладок в массиве `variants` (1 — полный сет, 2 — основное с соусом, 3 — отдельно соус, 4 — отдельно гарнир), чтобы каждая вкладка получила свой штрихкод FatSecret.
   - В начале `amount` каждого ингредиента пиши число и единицу измерения (`400 г (2 пачки)`, `2 шт (~120 г)`), а жирность (`5%`, `0,1%`) и категорию яиц (`С0`) оставляй в `name`.
   - В шагах `steps` оформляй `html` как `<div class="step-content"><p>...</p></div>` и явно указывай время (`15 минут`, `5 мин`), чтобы автоматически создавались кнопки таймеров.

3. **Обложка блюда (`<slug>.jpg`)**:
   - Если пользователь приложил готовое фото блюда — сохрани его в корень проекта под именем `<slug>.jpg`.
   - Если фото нет — сгенерируй аппетитное журнальное фото готового блюда при мягком дневном свете в эстетике сайта (светлая керамика, льняная текстура, без текста и водяных знаков) и сохрани в корень проекта как `<slug>.jpg`.

4. **Мгновенная публикация через `scripts/add-recipe.mjs`**:
   - Создай в корне проекта временный файл `new-recipe.json` со структурой объекта рецепта.
   - Запусти в терминале (Windows PowerShell, используй `;` вместо `&&`):
     ```powershell
     node scripts/add-recipe.mjs new-recipe.json --cleanup
     ```
   - Если пользователь попросил сразу выложить на сайт, выполни:
     ```powershell
     git add .; git commit -m "feat: add new recipe"; git push
     ```
