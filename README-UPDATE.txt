ПАКЕТ ОБНОВЛЕНИЯ САЙТА + КОНСТРУКТОР ИНГРЕДИЕНТОВ + СКИЛЛ (PP-RECIPES)
========================================================================

Что нового в этом архиве:
1. ПОЛНАЯ НАСТРОЙКА ЛЮБОГО ИНГРЕДИЕНТА БЕЗ СБОЯ РЕЦЕПТА («✏️ Вес / Замена»):
   - Теперь можно менять И название продукта, И его КБЖУ на 100 г, И его граммовку в рецепте (например: вместо 160 г клубники поставить 100 г голубики, а вместо 75 г шоколада поставить 50 г глазури), нажав кнопку «✓ Применить к этому продукту (остальной рецепт не менять)».
   - Все остальные продукты рецепта (творог, лаваш, яйца) остаются на своих местах и НЕ сбиваются!
   - Если просто вписать название нового продукта (например, «Голубика» или «Банан»), сайт сам автоматически подставит его базовое КБЖУ на 100 г в подсказки (либо можно вбить точные цифры со своей этикетки).
2. УДАЛЕНИЕ ЛЮБОГО ПРОДУКТА ИЗ РЕЦЕПТА («✕» / «🗑 Убрать продукт из рецепта»):
   - Напротив каждого ингредиента есть быстрая кнопка «✕» (и кнопка «🗑 Убрать продукт из рецепта» внутри карточки).
   - При удалении продукт зачёркивается (0 г), его калории, БЖУ и вес автоматически вычитаются из общего объёма и из расчёта «На 100 г», а вернуть его можно в 1 клик кнопкой «↩ Вернуть».
3. ДОБАВЛЕНИЕ СВОЕГО ПРОДУКТА В РЕЦЕПТ («➕ Добавить свой продукт в рецепт»):
   - Внизу списка ингредиентов появилась кнопка «➕ Добавить свой продукт в рецепт».
   - Можно добавить любой дополнительный ингредиент со своим весом в граммах и КБЖУ — он сразу появится в списке и учтётся во всех расчётах, списке покупок и штрихкоде FatSecret.
4. ИСПРАВЛЕНА МОБИЛЬНАЯ АДАПТАЦИЯ (без бокового сдвига и авто-зума iOS) + обновлён README.md и скилл для Antigravity.

⚠️ Файл базы рецептов assets/recipes-data.js в архив НЕ включён — все твои рецепты и вариации полностью сохранятся!
