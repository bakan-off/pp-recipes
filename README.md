# ПП · рецепты — Коллекция высокобелковых блюд (`pp-recipes`)

Статическая веб-витрина проверенных высокобелковых рецептов с точным пересчётом КБЖУ, штрихкодами для FatSecret, умным списком покупок и интерактивным кухонным режимом.

- **Рабочая витрина:** https://bakan-off.github.io/pp-recipes/index.html
- **Репозиторий:** https://github.com/bakan-off/pp-recipes

## Структура проекта

- `assets/recipes-data.js` — единая база данных всех рецептов и вариаций (`window.RECIPES`).
- `assets/app.js` — клиентское ядро без внешних зависимостей (каталог, расчёт пропорций и форм, умная корзина покупок, конструктор дневного рациона, генератор штрихкодов `GS1 EAN-13` для FatSecret и матричных `QR-кодов`, экспорт PNG-карточек и кухонные таймеры).
- `assets/styles.css` — журнальная дизайн-система со светлой (`Linen`) и тёмной (`Dark Espresso`) темами и поддержкой `View Transitions API`.
- `scripts/build.mjs` — скрипт сборки (`dist/`), автоматически генерирующий микроразметку `Schema.org/Recipe` (`JSON-LD`), `manifest.webmanifest` и `sw.js` (PWA офлайн-режим).
- `scripts/check.mjs` — автоматический тестовый раннер (проверка синтаксиса, валидация всех маршрутов и вариаций рецептов, модульные и DOM-тесты алгоритмов).

## Ключевые возможности

1. **Точный пересчёт рецепта «от продукта» и под диаметр формы:**
   - Кнопка `⚖ Изменить` напротив любого весового или штучного ингредиента пересчитывает весь рецепт, выход готового блюда и КБЖУ пропорционально количеству продукта, которое есть дома (с защитой от искажения процентов жирности `1%`, категорий яиц `С0`, маркировок `КСБ-80` и температур `170°C`).
   - Конвертер диаметра круглой формы (`14–26 см`) пересчитывает объём по отношению площадей круга ($S = \pi r^2$).
2. **Интеграция с FatSecret (штрихкоды GS1 EAN-13) и тарелочный калькулятор:**
   - Каждой вариации каждого рецепта присваивается постоянный валидный 13-значный штрихкод стандарта `GS1 EAN-13` во внутреннем префиксе `277` с контрольной цифрой Modulo-10.
   - При первом сканировании штрихкода камерой в приложении FatSecret достаточно один раз привязать к нему карточку КБЖУ на 100 г (кнопка «Скопировать карточку БЖУ» внутри окна штрихкода). После этого FatSecret навсегда связывает штрихкод с этим блюдом, позволяя вносить приём пищи за секунду.
   - Встроенный «Калькулятор вашей тарелки» мгновенно считает КБЖУ на произвольный вес готового блюда в граммах.
3. **Умная склейка в «Списке покупок»:**
   - Переключатель **«По отделам» ↔ «По блюдам»** автоматически суммирует одноимённые ингредиенты из разных рецептов (например, `400 г + 200 г = 600 г` творога или `2 шт + 3 шт = 5 шт (~315 г)` яиц) и раскладывает их по отделам супермаркета с отправкой в Telegram или MAX.
4. **Конструктор дневного рациона (`🎯 Мой рацион на день`):**
   - Позволяет задать дневную цель по калориям и БЖУ, собирать блюда на день и автоматически подбирать рецепты из каталога ровно под оставшийся дефицит белка и калорий.
5. **Экспорт PNG-карточки рецепта (`1080×1350`) с QR-кодом и штрихкодом:**
   - Отрисовка журнального постера рецепта через `Canvas API` с КБЖУ, пересчитанным списком ингредиентов, сканируемым штрихкодом `EAN-13` для FatSecret и `QR-кодом` прямой ссылки на выбранную вариацию.
6. **Кухонный режим с таймерами и голосовым управлением:**
   - Автоматическое превращение времени в шагах в кликабельные таймеры со звуковым сигналом (`Web Audio API`), удержание экрана включенным (`Screen Wake Lock API`) и переключение шагов голосом (`Web Speech API`: команды *«дальше»*, *«назад»*, *«таймер»*, *«пауза»*).

## Сборка и запуск автоматических тестов

Для синхронизации микроразметки `Schema.org/Recipe` и генерации файлов PWA (`manifest.webmanifest`, `sw.js`):

```bash
node scripts/build.mjs --sync-html
```

Для запуска полного набора автоматических проверок и модульных/DOM-тестов:

```bash
node scripts/check.mjs
```

Скрипт `scripts/check.mjs` автоматически проверяет:
- синтаксис всех `.js` и `.mjs` файлов;
- целостность всех 26 рецептов и 43 вариаций в `assets/recipes-data.js`;
- точность обратного пересчёта ингредиентов (`scaleAmount`, `extractPrimaryAmount`) и площадей форм (`calcPanRatio`);
- валидность контрольной суммы Modulo-10 и уникальность 95-битных штрихкодов `EAN-13` для всех 43 вариаций;
- корректность генерации матрицы `QR-кода` (`ISO/IEC 18004`);
- математическое сложение ингредиентов и распределение по отделам в `mergeCartIngredients`;
- DOM-рендеринг главной страницы каталога и страницы рецепта с параметрами URL (`?v=1&s=4&r=0.45`).
