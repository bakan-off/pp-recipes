# ПП · рецепты

**Ваши продукты. Ваш рецепт.**

Коллекция высокобелковых рецептов и интерактивный помощник для повседневной кухни. Подстраивайте блюда под свою упаковку, продукты и количество порций — с пересчётом КБЖУ, списком покупок и пошаговым режимом готовки.

**[Открыть сайт →](https://bakan-off.github.io/pp-recipes/)** · **[Редактор рецептов →](https://bakan-off.github.io/pp-recipes/editor.html)**

Автор проекта: Андрей Баканов · [@bakan_off](https://t.me/bakan_off)

## Не просто читать — готовить под себя

- **Своя пачка и свои порции.** Изменяйте количество одного ингредиента или масштабируйте всё блюдо; пересчитывайте выпечку под диаметр формы.
- **Свои продукты.** Указывайте КБЖУ с этикетки и сохраняйте часто используемые продукты в «Моей кухне».
- **Согласованные количества.** Пересчитанные ингредиенты используются в покупках, рационе, экспорте и связанных количествах в шагах. Неоднозначные числа в старых шагах заменяются ссылкой на актуальный список, а не угадываются.
- **Мои версии.** Сохраняйте удачные изменения, порции и заметки; оригинальные рецепты остаются неизменными.
- **Выбор без лишнего шума.** Поиск, избранное, категории, фильтры по продуктам и сравнение вариантов на 100 г.
- **Покупки и рацион.** Собирайте дневное меню и общий список продуктов по отделам или блюдам.
- **Готовка шаг за шагом.** Крупный текст, закреплённая навигация, таймеры, восстановление шага и удержание экрана в поддерживаемых браузерах. Доступ к микрофону не требуется.
- **FatSecret.** Сохранены постоянные EAN-13 всех исходных вариаций, QR-ссылки и экспорт PNG-карточки. При изменении состава проверяйте КБЖУ записи в дневнике: штрихкод варианта не меняется.
- **Без регистрации.** Личные данные остаются в браузере. Есть экспорт и восстановление резервной копии JSON.

## Дизайн и доступность

Светлая и тёмная темы, адаптивный интерфейс, облегчённые изображения WebP в трёх размерах, переходы View Transitions в поддерживаемых браузерах и поддержка `prefers-reduced-motion`. В браузерах без новых API сохраняется обычная навигация.

Основной рецепт доступен в статическом HTML даже без JavaScript. Для пересчётов, сохранений и таймеров нужен JavaScript.

## Для автора: ИИ и ручное редактирование

Откройте `editor.html`, чтобы создать рецепт с нуля, загрузить JSON от ИИ или изменить рецепт из каталога. Редактор поддерживает ингредиенты с данными по этикетке, варианты, шаги, предпросмотр и локальный черновик.

1. Заполните рецепт, проверьте готовый вес и КБЖУ.
2. Для динамического названия и количества используйте «Вставить продукт» в шаге: создаётся ссылка `{{ingredient:0}}` (индекс в массиве ingredients, с нуля).
3. Скачайте JSON. Если выбрано новое фото, скачайте и его.
4. Положите фото в корень локального репозитория.
5. Добавьте или обновите рецепт:

```sh
node scripts/add-recipe.mjs path/to/recipe.json
```

Скрипт проверяет данные, обновляет общую базу и страницу, пересобирает сайт и запускает проверки. Сетевой генерации изображений и подстановки чужой фотографии вместо отсутствующей нет. Сам редактор в GitHub ничего не публикует и не содержит токенов.

## Локальный запуск

Для готовой статики не нужна установка npm-зависимостей. Нужен Node.js 20.19+ (рекомендуется актуальная LTS).

```sh
node scripts/serve.mjs
```

Откройте `http://127.0.0.1:4173`. Не используйте двойной щелчок по HTML (`file://`) для проверки PWA.

## Сборка и проверки

```sh
npm run build
npm test
```

Сборка обновляет готовые HTML в корне и создаёт `dist/`, микроразметку Recipe, карту сайта, манифест и Service Worker с версией по содержимому. Корень репозитория уже готов для GitHub Pages.

Для браузерных тестов:

```sh
npm ci
npx playwright install chromium
npm run test:browser
```

Тесты поднимают отдельный локальный сервер, проверяют страницы и варианты, пересчёт, покупки, рацион, сохранения, редактор, экспорт и офлайн-перезагрузку. Снимки и результаты попадают в `qa-output/`.

### Повторная оптимизация новых фото — необязательно

Уже подготовленные WebP включены в репозиторий. Для новых фотографий:

```sh
python3 -m pip install Pillow
python3 scripts/optimize-images.py
npm run build
```

Исходные JPG/PNG сохраняются. Скрипт создаёт версии 480, 960 и 1440 px без увеличения исходного разрешения. Если оптимизированной версии нового фото пока нет, сайт использует исходник.

## Что важно знать

- КБЖУ — расчёт по исходным данным и этикеткам, не лабораторное измерение. Для продукта без этикетки используется приблизительная оценка, готовый вес после замены также оценочный.
- Числа времени и температуры не масштабируются. Замена ингредиента не гарантирует ту же текстуру: контролируйте консистенцию и готовность.
- В старых свободных текстах нельзя безопасно угадать каждую связь числа с продуктом. Для новых и отредактированных шагов используйте явные ссылки `{{ingredient:N}}`.
- Офлайн работают ранее открытые рецепты и закэшированные ресурсы. Для первого открытия нового рецепта нужен интернет.
- Сохранения не синхронизируются между устройствами автоматически. Перед очисткой браузера скачайте резервную копию. Черновик авторского редактора резервируется отдельно скачанным JSON рецепта.
- Фоновая работа таймеров и Wake Lock зависит от браузера и операционной системы. Сайт не обещает надёжную сигнализацию при закрытом браузере или заблокированном телефоне.
