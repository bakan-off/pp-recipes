# ПП · рецепты — Коллекция высокобелковых блюд (`pp-recipes`)

Статическая веб-витрина проверенных высокобелковых рецептов с точным пересчётом КБЖУ, индивидуальной заменой ингредиентов под свою упаковку, штрихкодами для FatSecret, умным списком покупок и интерактивным кухонным режимом.

- **Рабочая витрина:** [https://bakan-off.github.io/pp-recipes/index.html](https://bakan-off.github.io/pp-recipes/index.html)
- **Репозиторий:** [https://github.com/bakan-off/pp-recipes](https://github.com/bakan-off/pp-recipes)
- **Автор проекта:** Андрей Баканов ([@bakan_off](https://t.me/bakan_off))

## Структура проекта

- `assets/recipes-data.js` — единая база данных всех рецептов и их вариаций (`window.RECIPES`).
- `assets/app.js` — клиентское ядро без внешних зависимостей (каталог, индивидуальная замена ингредиентов со своим КБЖУ и обратный пересчёт пропорций, конвертер диаметра форм, умная корзина покупок, конструктор дневного рациона, генератор штрихкодов `GS1 EAN-13` для FatSecret и матричных `QR-кодов`, экспорт PNG-карточек, интерактивный демо-гид и кухонные таймеры).
- `assets/styles.css` — журнальная дизайн-система со светлой (`Linen`) и тёмной (`Dark Espresso`) темами, поддержкой `View Transitions API` и полной мобильной адаптацией (без горизонтального скролла и авто-зума полей ввода на iOS/Android).
- `scripts/add-recipe.mjs` — CLI-утилита для быстрой публикации новых рецептов из JSON-описания с автоматической синхронизацией HTML, счётчиков тестов и сборкой `dist/`.
- `scripts/build.mjs` — скрипт сборки (`dist/`), автоматически генерирующий микроразметку `Schema.org/Recipe` (`JSON-LD`), `manifest.webmanifest` и `sw.js` (PWA офлайн-режим).
- `scripts/check.mjs` — автоматический тестовый раннер (проверка синтаксиса, валидация всех маршрутов и вариаций рецептов, модульные и DOM-тесты алгоритмов).
- `.agent/skills/pp-recipe-publisher/SKILL.md` — локальный навык для агента Google Antigravity, позволяющий публиковать новые рецепты за 1–2 минуты по команде `добавь рецепт`.

## Ключевые возможности

1. **Индивидуальная замена продукта на свой (по этикетке) и пересчёт рецепта «от пачки» (`⚖ Вес / Замена`):**
   - Напротив каждого весового или штучного ингредиента расположена кнопка `⚖ Вес / Замена`. Каждая позиция в списке настраивается **независимо по своему индексу** — если в рецепте используются два разных вида творога или сыра, замена одного продукта не затрагивает второй.
   - **Свой продукт с упаковки:** можно вписать название и КБЖУ на 100 г со своей пачки (например, заменить обезжиренный творог или сыр из рецепта на свой бренд) — сайт мгновенно пересчитает дельту калорий, белков, жиров и углеводов как на весь объём блюда, так и на 100 г и 1 порцию.
   - **Пересчёт пропорций от веса пачки и диаметра формы:** можно указать имеющееся количество любого продукта (например, пачка `180 г` вместо `360 г`) или выбрать диаметр своей формы для выпечки (`14–26 см`, пересчёт по отношению площадей круга $S = \pi r^2$) — все остальные ингредиенты масштабируются автоматически (с защитой от искажения процентов жирности `0.1%`, категорий яиц `С0`, маркировок `КСБ-80` и температур `180°C`).
2. **Интеграция с FatSecret (штрихкоды GS1 EAN-13) и калькулятор тарелки:**
   - Каждой вариации каждого рецепта присваивается постоянный валидный 13-значный штрихкод стандарта `GS1 EAN-13` во внутреннем префиксе `277` с контрольной цифрой Modulo-10.
   - Кнопки **«Карточка и штрихкод»** и **«Штрихкод FatSecret»** открывают окно со сканируемым прямо с экрана штрихкодом, готовой карточкой БЖУ для буфера обмена и превью постера (с возможностью скопировать картинку через `Ctrl+V` или скачать `PNG`).
   - Встроенный «Калькулятор вашей тарелки» мгновенно считает КБЖУ на произвольный вес готовой порции в граммах.
3. **Умная склейка в «Списке покупок» (`🛒`):**
   - Переключатель **«По отделам» ↔ «По блюдам»** автоматически суммирует одноимённые ингредиенты из разных рецептов (например, `400 г + 200 г = 600 г` творога или `2 шт + 3 шт = 5 шт (~315 г)` яиц) и раскладывает их по отделам супермаркета с отправкой в Telegram или MAX.
4. **Конструктор дневного рациона (`🎯 Мой рацион на день`):**
   - Позволяет задать дневную цель по калориям и БЖУ (`Сушка` / `Баланс` / `Набор`), собирать блюда на день и автоматически подбирать рецепты из каталога ровно под оставшийся дефицит белка и калорий.
5. **Интерактивный демо-гид (`✨ Что умеет сайт`) и обратная связь с автором:**
   - Наглядная экскурсия по всем возможностям сайта с живым симулятором пересчёта КБЖУ и пачки прямо в модальном окне, а также быстрая отправка идей автору в Telegram (`@bakan_off`) с автоматической меткой страницы.
6. **Кухонный режим с таймерами и голосовым управлением:**
   - Автоматическое превращение времени в шагах в кликабельные таймеры со звуковым сигналом (`Web Audio API`), удержание экрана включенным (`Screen Wake Lock API`) и переключение шагов голосом (`Web Speech API`: команды *«дальше»*, *«назад»*, *«таймер»*, *«пауза»*).

## Быстрое добавление новых рецептов

Добавить новый рецепт можно через скрипт `scripts/add-recipe.mjs`:

```bash
node scripts/add-recipe.mjs path/to/recipe.json
```

Скрипт автоматически обновляет `assets/recipes-data.js`, создаёт HTML-страницу рецепта, синхронизирует счётчики в `scripts/check.mjs`, запускает сборку `node scripts/build.mjs --sync-html` и прогоняет тесты `node scripts/check.mjs`.

## Сборка и запуск автоматических тестов

Для синхронизации микроразметки `Schema.org/Recipe` и генерации файлов PWA (`manifest.webmanifest`, `sw.js`):

```bash
node scripts/build.mjs --sync-html
```

Для запуска полного набора автоматических проверок и модульных/DOM-тестов:

```bash
node scripts/check.mjs
```
